## 1) Executive Summary

The EURUSD H1 signal pipeline has been validated on the sealed test set. The original dual-model approach (BUY+SELL combined) failed on test (0.347 precision, below 0.400 breakeven). After iteration, the accepted configuration is:

- **BUY-only** (SELL lane disabled — non-viable on test)
- **Session filter**: London + NY hours only (suppress Asian session false positives)
- **Cross-filter**: 0.60
- **Cooldown**: 4 bars

This configuration achieves **0.415 precision on the sealed test set** (41 signals over 109 days, 0.37/day), clearing the 0.400 breakeven by +0.015.

Current operating candidate:
- CROSS_FILTER = 0.60
- COOLDOWN_BARS = 4
- BUY_ONLY = True
- SESSION_FILTER = True (London + NY)

Final test snapshot:
- BUY final: 0.415 (41 signals, 0.37/day)
- SELL final: disabled (0 signals)
- COMBINED = BUY-only: 0.415
- Breakeven: 0.400
- Test window: 2026-02-02 to 2026-07-03 (2,626 H1 bars, 109 trading days)

Interpretation:
- Session filter is the critical addition — without it, BUY-only maxes out at 0.355.
- SELL lane adds zero value; removed entirely.
- Strategy crosses breakeven on unseen data.
- ~58% false positive rate is acceptable for an alert generator (not auto-trader).

## 4) Notebook Pipeline (Current Logic)

### 4.1 BUY notebook (eurusd_buy.ipynb)

Contains:
- data loading and validation
- feature engineering (technical + time/session + D1 context)
- path-dependent BUY labels using ATR-scaled TP/SL and forward window
- ATR/grid tuning utilities
- feature selection via noise-injection + voting (RF/LGBM/LogReg)
- nested-CV classification training (PR-AUC objective)
- threshold calibration (precision-recall operating point)
- final model bundle save

### 4.2 SELL notebook (eurusd_sell.ipynb)

Mirrors BUY notebook with SELL-direction label logic. **Currently not used in production** — SELL lane failed on test set.

### 4.3 Combiner notebook (signal_combiner.ipynb)

Combines BUY model with rule-based gating into final decision layer:
- Scores BUY model on validation and test windows (SELL model loaded but signals suppressed)
- Decision logic:
  - BUY fires if `buy_proba >= 0.678` AND `sell_proba < 0.60` (cross-filter)
  - SELL lane disabled entirely (`BUY_ONLY = True`)
  - Session gate: signals suppressed outside London (07:00–15:59 UTC) and NY (13:00–21:59 UTC)
  - Cooldown: max 1 signal per 4 bars
- Evaluation: precision table, cross-filter sweep, side-by-side comparison, test visualization
- Exports test combined signals to CSV

## 5) Data/Label/Metric Contract (Current)

Label mechanics:
- Binary lane labels are generated by TP/SL race over forward bars.
- Conservative tie handling: if TP and SL hit in same bar, label defaults to negative outcome.

Current key label parameters (from model bundles):
- ATR_TP_MULT = 1.5
- ATR_SL_MULT = 1.0
- FORWARD_BARS = 6

Breakeven precision formula:
- breakeven = ATR_SL_MULT / (ATR_TP_MULT + ATR_SL_MULT)
- with 1.0 and 1.5 -> 0.400

Optimization focus in training:
- PR-AUC / average precision for imbalanced classification.

Production decision gates (applied after model inference):
- Cross-filter: suppress if `sell_proba >= 0.60`
- Session filter: suppress if outside London+NY hours (see y1-label-definition.md "Final Setup")
- Cooldown: suppress if <4 bars since last signal

## 6) Current Findings and Read of System Health

What is working:
- BUY-only + session filter clears breakeven on sealed test set (0.415 vs 0.400).
- Session filter (London+NY only) is the single most impactful rule-based gating.
- Cross-filter at 0.60 provides the best precision-to-signal-count trade-off.
- Cooldown prevents signal clustering without hurting precision.

What is still weak:
- SELL lane is non-viable (3 signals, 0.333 precision on test) — disabled entirely.
- ~58% false positive rate means downstream agent filtering is essential.
- 0.37 signals/day is sparse; a BUY-only long-only strategy misses downside moves.
- Overfit gap of +0.075 from validation suggests model is not fully generalizing.

Practical implication:
- The system is ready for a production prediction script.
- Current setup is an alert generator, not a standalone trading system.
- SELL coverage would need either model retraining or the inverted-pair trick (run BUY model on 1/EURUSD).
