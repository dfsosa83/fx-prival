## 4) Notebook Pipeline (Current Logic)

### 4.1 BUY notebook (eurusd_buy.ipynb)

Contains:
- data loading and validation
- feature engineering (technical + time/session + D1 context)
- path-dependent BUY labels using ATR-scaled TP/SL and forward window
- ATR/grid tuning utilities
- feature selection via noise-injection + voting (RF/LGBM/LogReg)
- nested-CV classification training (PR-AUC objective)
- threshold calibration (precision-recall operating point)
- final model bundle save

### 4.2 SELL notebook (eurusd_sell.ipynb)

Mirrors BUY notebook with SELL-direction label logic:
- SELL TP below entry, SL above entry
- mirrored hit-testing in forward bars
- same feature engineering and model selection framework

### 4.3 Combiner notebook (signal_combiner.ipynb)

Combines independent BUY/SELL bundles into one action layer:
- scores both models on validation and test windows
- conflict filter:
  - BUY fires if buy_proba >= buy_threshold and sell_proba < CROSS_FILTER
  - SELL fires if sell_proba >= sell_threshold and buy_proba < CROSS_FILTER
  - simultaneous threshold exceedance -> conflict -> no trade
- cooldown:
  - suppresses repeated same-direction signals within COOLDOWN_BARS
  - BUY and SELL maintain independent cooldown timers
- evaluation table includes:
  - standalone
  - +cross-filter
  - +cross-filter+cooldown
- exports test combined signals to CSV

## 5) Data/Label/Metric Contract (Current)

Label mechanics:
- Binary lane labels are generated by TP/SL race over forward bars.
- Conservative tie handling: if TP and SL hit in same bar, label defaults to negative outcome.

Current key label parameters seen in bundles/runs:
- ATR_TP_MULT = 1.5
- ATR_SL_MULT = 1.0
- FORWARD_BARS = 6 (in latest combiner checks)

Breakeven precision formula:
- breakeven = ATR_SL_MULT / (ATR_TP_MULT + ATR_SL_MULT)
- with 1.0 and 1.5 -> 0.400

Optimization focus in training:
- PR-AUC / average precision for imbalanced classification.
